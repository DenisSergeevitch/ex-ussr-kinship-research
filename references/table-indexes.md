# Локальные таблицы записей

Для полученного от пользователя или разрешённого к локальной обработке индекса CSV/XLSX можно найти строки и собрать соседние записи по указанным полям. Не изменяйте исходный файл. Данные и результаты держите вне репозитория навыка, соблюдайте ограничения источника и правила приватности дела.

```bash
python scripts/table_index.py <дело>/sources/index.csv --name-column 'Фамилия' \
  --variant 'Петров' --variant 'Петрова' \
  --group-by 'Отец' --group-by 'Мать' --out <дело>/sources/table-search.json
```

CSV читается как UTF-8, разделитель — запятая, первая строка — непустые уникальные заголовки. Для XLSX нужен `openpyxl`; если листов несколько, обязательно передайте `--sheet 'Рождения'`. Столбец поиска и вариант можно указать несколько раз. По умолчанию сравнивается всё поле после нормализации Unicode, регистра и пробелов; `--contains` включает поиск подстроки. Варианты задаёт исследователь: скрипт не угадывает транслитерацию или окончания. Если файл содержит формулы, подготовьте копию с рассчитанными значениями: скрипт не вычисляет формулы. Другие форматы, разделители и строки заголовка требуют предварительной подготовки копии.

`--out` создаёт только новый файл и откажется перезаписать существующий, включая источник. Без него результат выводится в консоль; не перенаправляйте вывод командной оболочки в исходный файл, поскольку оболочка очистит его до запуска программы.

Результат JSON содержит SHA-256 исходного файла, имя листа, номер строки CSV (начало записи, включая многострочные) или XLSX, исходные значения полей, параметры поиска и найденные варианты. Группа формируется только при совпадении **всех** выбранных непустых полей; в неё попадают и строки без совпадения поиска. Совпавшие строки с пустым полем группировки перечислены отдельно; без `--group-by` все совпадения перечислены отдельно. Группировка не учитывает время и место автоматически: одинаковые имена могут относиться к разным семьям, а варианты написания могут разделить одну семью. Если даты или места существенны, включайте их в анализ и проверяйте вручную.

Найдите исходный документ по сведениям строки, проверьте прочтение и контекст, внесите подтверждённые артефакты и проверенный охват в обычные реестры дела. Совпадение полей не устанавливает личность, семейную связь или независимое подтверждение; отсутствие совпадения в таблице не устанавливает отсутствие записи в книге. JSON может содержать персональные данные всех полей подходящих строк — перед передачей удалите лишние сведения. Пустая выдача охватывает только указанный файл, лист, поля и варианты.
