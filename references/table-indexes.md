# Локальные таблицы записей

Для полученного от пользователя или разрешённого к локальной обработке индекса CSV/XLSX можно найти строки и собрать соседние записи по указанным полям. Не изменяйте исходный файл. Данные и результаты держите вне репозитория навыка, соблюдайте ограничения источника и правила приватности дела.

```bash
python scripts/table_index.py <дело>/sources/index.csv --name-column 'Фамилия' \
  --variant 'Петров' --variant 'Петрова' \
  --group-by 'Отец' --group-by 'Мать' --out <дело>/sources/table-search.json
```

CSV читается как UTF-8, разделитель — запятая, первая строка — непустые уникальные заголовки. Для XLSX нужны необязательные `openpyxl` и включённый `defusedxml`; без них продолжайте другими средствами анализа или CSV. Если листов несколько, передайте `--sheet 'Рождения'`. Столбец поиска и вариант можно указать несколько раз. По умолчанию сравнивается всё поле после нормализации Unicode NFKC, регистра и пробелов; `--contains` включает поиск подстроки. Нормализованное совпадение — поисковая наводка, не тождество исходного написания. Варианты задаёт исследователь: скрипт не угадывает транслитерацию или окончания.

Формулы XLSX отвергаются, включая заголовок: скрипт не рассчитывает их и не подменяет устаревшим кэшем. Для анализа значений подготовьте отдельную копию имеющимися средствами, сохраняя оригинал. CSV читается как текст, даже если значение начинается с `=`. Внешние связи и макросы XLSX не сохраняются и не запускаются. Значения ячеек преобразуются в строки: форматирование Excel, например ведущие нули числового кода, не восстанавливается; даты и числа могут отличаться от отображения в Excel. При существенном различии проверьте исходную ячейку. Пробелы по краям заголовков убираются; значения строк остаются без поисковой нормализации. Другие форматы, разделители и строки заголовка требуют подготовки копии.

Помощник обрабатывает файл целиком в памяти: максимум 32 МиБ входа, 128 МиБ распакованных частей XLSX, 1024 части архива, 100 000 строк с заголовком, 256 столбцов и миллион ячеек. Повторные ZIP-части, шифрование и превышение бюджета отвергаются до выдачи результата; текст XML читает защищённый парсер. Размеры листа из метаданных не принимаются за фактический охват: читаются реальные строки с проверкой пределов. Это ограничения помощника, не предел исследования: крупный индекс анализируйте имеющимися средствами или подготовьте относящуюся к вопросу часть, сохранив связь с оригиналом и границы выборки.

`--out` создаёт только новый файл вне папки навыка с частными правами доступа и откажется заменить существующий файл или символическую ссылку, включая источник. Полный JSON подготавливается до публикации нового файла; временный файл удаляется. Без `--out` результат выводится в консоль; не перенаправляйте вывод командной оболочки в исходный файл, поскольку оболочка очистит его до запуска программы.

Результат JSON содержит SHA-256 прочитанных байтов, имя листа, номер строки CSV (физическое начало записи, включая многострочные) или XLSX, строковые значения полей, параметры поиска и найденные варианты. Файл читается один раз; постоянного кэша и сетевых обращений нет. Группа формируется только при совпадении **всех** выбранных непустых полей; в неё попадают и строки без совпадения поиска. Совпавшие строки с пустым полем группировки перечислены отдельно; без `--group-by` все совпадения перечислены отдельно. Группировка не учитывает время и место автоматически: одинаковые имена могут относиться к разным семьям, а варианты написания могут разделить одну семью. Если даты или места существенны, включайте их в анализ и проверяйте вручную.

Найдите исходный документ по сведениям строки, проверьте прочтение и контекст, внесите подтверждённые артефакты и проверенный охват в обычные реестры дела. Совпадение полей не устанавливает личность, семейную связь или независимое подтверждение; отсутствие совпадения в таблице не устанавливает отсутствие записи в книге. JSON может содержать персональные данные всех полей подходящих строк — перед передачей удалите лишние сведения. Пустая выдача охватывает только указанный файл, лист, поля и варианты.
