**Малакаи насабшиносӣ барои агентҳои зеҳни сунъӣ бо авлавияти далелҳо (Codex, Claude Code ва дигар муҳитҳои Agent Skills).** Он агентро ба муҳаққиқи бодиққати таърихи оила дар ҳудуди собиқ ИҶШС, Иттиҳоди Шӯравӣ ва Империяи Русия табдил медиҳад. Агент китобҳои калисо ва сабтҳои ҳолати шаҳрвандӣ, парвандаҳои ҳарбӣ, бадарға ва саркӯб, инчунин сканҳои бойгонии бе индексро мехонад. Пайдоиши ҳар бозёфтро пайгиришаванда нигоҳ медорад, сабтро аз тафсири он ҷудо мекунад ва равшан мегӯяд, ки чӣ исбот шудаасту чӣ нашудааст.

Фарогирӣ ҳамаи 15 ҷумҳурии собиқи шӯравиро дар бар мегирад: Русия, Украина, Беларус, Молдова, Эстония, Латвия, Литва, Гурҷистон, Арманистон, Озарбойҷон, Қазоқистон, Қирғизистон, Тоҷикистон, Туркманистон ва Ӯзбекистон. Бойгониҳо аз рӯйи салоҳияти таърихӣ дар замони рӯйдод ва нигаҳбони кунунии ҳуҷҷат интихоб мешаванд; мисоли минтақавӣ ҷойи таҳқиқи маҳаллиро намегирад.

Дастурҳои малака ба русӣ навишта шудаанд, вале **агент бо шумо ба забони худатон суҳбат мекунад**: англисӣ, украинӣ, русӣ, лаҳистонӣ, олмонӣ ва ғайра. Манбаъҳоро бо имлои аслӣ ва тарҷума иқтибос мекунад ва дархостҳои ҷустуҷӯро ба забонҳои сабтҳо месозад.

## Чӣ кор мекунад

- **Оғоз ва ҳудуди парванда.** Як саволи таҳқиқ, маълумоти маълум, кӣ метавонад зинда бошад ва кадом амалҳо берун аз ҳудуди иҷозатанд.
- **Феҳристҳои бозсанҷишаванда.** Шахсон, артефактҳо, иддаоҳо, робитаҳо ва журнали пурраи ҷустуҷӯ (CSV), ҳамроҳ бо қолаби гузориши ниҳоӣ.
- **Модели салоҳияти таърихӣ.** Ҳар рӯйдодро ба давлат, вилоят, ноҳия, ҳавзаи калисо ё идораи сабти ҳолати шаҳрвандӣ *дар санаи рӯйдод* мепайвандад, на ба харитаи имрӯза.
- **Ҷадвалҳои вариантҳои ном.** Шаклҳои русии пеш аз ислоҳот, украинӣ, лаҳистонӣ, руминӣ, олмонӣ ва идиш, номи падар, насаби пеш аз издивоҷ ва транслитератсияҳо.
- **Стратегияи манбаъ.** Аввал аслҳо, сипас феҳристҳои расмӣ, индексҳо, маҷмӯаҳои нашршудаи ҳуҷҷатҳо ва танҳо баъд дарахтони оилавӣ ва форумҳо ҳамчун роҳнамо барои ҷустуҷӯ.
- **Протоколи далелҳо.** Ба иддаоҳо на фоиз, балки мақомҳои шарҳпазир дода мешаванд: `hypothesis`, `single-source`, `corroborated`, `strongly-corroborated`, `contradicted`, `unresolved`. Нусхаҳо ва оинаҳои як сабт `independence_group`-и муштарак доранд, бинобар ин ҳеҷ гоҳ далелҳои мустақил ҳисоб намешаванд.
- **Муайян кардани шахсият.** Ҳамномҳо то пайдо шудани далели фарқкунанда — рақами хона, волидон, падару модари таъмидӣ, санаи дақиқи таваллуд ё қисми ҳарбӣ — бо `person_id`-ҳои ҷудогона мемонанд.
- **Скрипти санҷиш.** Пеш аз навиштани хулосаҳо якпорчагии истинодҳоро месанҷад ва тасдиқи заифро нишон медиҳад. Гурӯҳи мустақилият танҳо вақте ҳисоб мешавад, ки артефакти истинодшуда ба он тааллуқ дошта бошад; тасдиқро бо эълони холӣ эҷод кардан мумкин нест. Гузориши ниҳоиро низ месанҷад: ҳар ID-и зикршуда бояд дар феҳристҳо бошад ва ҳар мақом ба онҳо мувофиқат кунад. Ҷамъбаст нишон медиҳад, ки чӣ ҳанӯз тасдиқ нашудааст ё нохонда қайд шудааст.
- **Дархост ба муассисаҳо.** Ба бойгониҳо, китобхонаҳо, донишгоҳҳо ва осорхонаҳо тавассути почтаи электронӣ ё абзорҳои расмии веб дархостҳои мушаххас таҳия мекунад ва бо иҷозат мефиристад. Ҳангоми зарурат пайвасти дастгиришавандаи почта ё номаи омодаи ирсолро пешниҳод мекунад. Натиҷаро сабт мекунад, ирсоли такрориро пешгирӣ мекунад ва ҷавобҳоро ҳамчун далел баррасӣ мекунад. Ба [дастури мукотиба](references/correspondence.md) нигаред.
- **Хизматрасониҳои давлатӣ.** Бо санҷидани ҳуқуқи муроҷиат ва тарзи расонидани натиҷа роҳи расмии дархости сабти ҳолати шаҳрвандӣ ё бойгониро интихоб мекунад ([порталҳои давлатӣ](references/government-portals.md)).
- **Гузориши ниҳоӣ.** Ҳар робитаи хешутаборӣ пайванд ба пайванд бо ихтилофҳо, ҷустуҷӯҳои бенатиҷа ва қадамҳои мушаххаси оянда нишон дода мешавад.
- **Таҳқиқи ҳадафноки сабтҳои индексшуда.** Тавассути ҷаласаи мавҷудаи қонунии браузер китобҳои мувофиқи FamilySearch-ро аз рӯйи маҳал ё DGS меёбад, сабтҳои мушаххасро мебинад ва танҳо пораҳои далелии иҷозатдодаи манбаъро нигоҳ медорад. Абзорҳои маҳаллӣ дар пораҳои сабтшуда хешовандон, шоҳидон ва вариантҳои номро ҷустуҷӯ карда, замина ва маблағҳои санҷишии файлҳоро нигоҳ медоранд. [Раванди кор ва ҳудуди фарогирӣ](references/familysearch-indexes.md).
- **FamilySearch MCP-и пайвастшуда.** Сервери пайвастро барои ҷустуҷӯҳои сохторӣ, профилҳо, хешовандон, манбаъҳо ва тағйироти иҷозатдодаи дарахт бо ҳудуди равшан ва хондани такрорӣ барои санҷиш истифода мебарад. Ҷустуҷӯи индексшударо аз хондани сканҳои бе индекс ҷудо нигоҳ медорад ва имкониятҳои воқеии пайвасткунанда дар браузер, махфият ва навиштанро месанҷад. [Раванди кор ва маҳдудиятҳои дастрасӣ](references/familysearch-mcp.md).
- **Ҷустуҷӯи манбаъҳои Ҷанги якуми ҷаҳон.** Гузоришҳо ва сабтҳои беморхона, мукофот ва асирони ҳарбии GWAR-ро аз рӯйи шахс ё маҳал ҷустуҷӯ мекунад; барои кушодани номи таҳрифшудаи маҳал навишти номҳои шаҳру деҳаро дар кортҳои сабтшуда муқоиса карда, баъд тасвири аслиро меёбад. [Раванди кор](references/ww1-search.md). Ҳар ду абзор ба феҳристи мавҷудаи артефактҳо ва журнали ҷустуҷӯ маълумот медиҳанд; онҳо шахсият ё хешутабориро худкор муқаррар намекунанд.

Таърихи нашрҳо: [рӯйхати тағйирот](references/changelog.md).

## Насб

Агар Node.js насб бошад, метавонед аз [Skills CLI](https://github.com/vercel-labs/skills)-и ихтиёрӣ истифода баред:

```bash
npx skills add https://github.com/DenisSergeevitch/ex-ussr-kinship-research
```

CLI имкон медиҳад агенти худро интихоб кунед ва одатан дар лоиҳаи ҷорӣ насб мекунад; барои насби шахсӣ дар ҳамаи лоиҳаҳо `-g` илова кунед. Талаботи кунунии Node.js-ро дар ҳуҷҷатҳои он бинед.

Ё репозиторийро мустақиман ба ҷузвдони малакаҳои агенти худ клон кунед:

```bash
# Codex
git clone https://github.com/DenisSergeevitch/ex-ussr-kinship-research ~/.codex/skills/ex-ussr-kinship-research

# Claude Code (малакаҳои шахсӣ)
git clone https://github.com/DenisSergeevitch/ex-ussr-kinship-research ~/.claude/skills/ex-ussr-kinship-research
```

Барои як лоиҳа ҷузвдонро дар `.claude/skills/`-и дохили репозиторий ҷойгир кунед. Скриптҳо танҳо Python 3 ва китобхонаи стандартиро талаб мекунанд; барои `build_pdf.py` браузери асосаш Chromium низ лозим аст.

## Истифода

Саволи оилавиро шарҳ диҳед. Агент бо маълумоти дастрас кор мекунад ва ҳангоми интизори ҷавоб ба саволҳо ё дархостҳои дастрасӣ таҳқиқро идома медиҳад. Масалан:

- *«Падари бобоям дар солҳои 1930 ба Қазоқистон бадарға шудааст. Кӯмак кун, ки волидонашро дар сабтҳои калисо ёбам.»*
- *«Инҳо сканҳои шаҳодатномаи ақди никоҳ ва корти сарбозанд. Бисанҷ, ки онҳо ба як шахс тааллуқ доранд ё не, ва занҷири далелҳо бисоз.»*
- *«Ҳавзаи калисо ва навори дурусти FamilySearch-ро барои деҳаи Подолия дар солҳои 1890 ёб ва сабтҳои таваллудро барои насаби X бихон.»*

Маълумоти хусусии парвандаро берун аз нусхаи кории Git-и малака нигоҳ доред. Аз ҷузвдони малака:

```bash
python scripts/init_case.py --case-dir ~/kinship-cases/my-case --research-question "Who were Maria's parents?" --subject-label "Maria"
python scripts/hash_artifact.py ~/kinship-cases/my-case/scans/marriage-1902.jpg   # SHA-256 барои ҳар артефакти сабтшуда
python scripts/audit_evidence.py --case-dir ~/kinship-cases/my-case             # санҷиши феҳристҳо пеш аз гузориши ниҳоӣ
python scripts/build_pdf.py --html ~/kinship-cases/my-case/pdf-source/report.html --out ~/kinship-cases/my-case/report.pdf
```

`init_case.py` эҷоди парвандаро дар дохили ҷузвдони малака, ҳатто бо `--force`, рад мекунад. Git ҳамчун ҳифзи иловагӣ номҳои маъмулии ҷузвдонҳои кӯҳнаи парвандаро нодида мегирад; пеш аз саҳмгузорӣ, хусусан ҳангоми кӯчонидани парвандаи мавҷуда, файлҳои ба индекс иловашударо санҷед.

Барои `build_pdf.py` Chrome, Chromium ё Edge бояд насб бошад (ё `CHROME_PATH` нишон дода шавад). Бо `--png-dir`, агар `pypdfium2` дастрас бошад, саҳифаҳоро барои бозбинӣ ба PNG низ табдил медиҳад.

HTML-и статикиро бо тасвирҳои маҳаллӣ ё дарунсохт истифода баред. HTML-и фаъол ва манбаъҳои тасвири шабакавӣ рад мешаванд; пайвандҳои манбаъҳо пахшшаванда мемонанд. Агар табдил ноком шавад, PDF-и пешинаи натиҷа нигоҳ дошта мешавад.

## Дарахти оилавӣ дар формати GEDCOM

[GEDCOM](https://gedcom.io/specs/) (`.ged`) формати стандартии мубодилаи маълумоти насабшиносӣ аст. Ҳангоми дархости сохтани дарахт ё содироти он агент файли маҳаллӣ бо истинод ба манбаъҳо ва қайдҳои дараҷаи исбот омода мекунад. Барои мутобиқат, интихоби пешфарз GEDCOM 5.5.1 бо рамзгузории UTF-8 аст; агар корбар версияи дигари дастгиришаванда, масалан GEDCOM 7-ро интихоб кунад, ҳамон истифода мешавад.

Дарахти мавҷуда маводи ибтидоӣ ва роҳнамои ҷустуҷӯ аст, худ аз худ далел нест. Файли аслӣ нигоҳ дошта мешавад ва рӯйнавис намешавад; маълумоти тасдиқнашуда ва номуайянӣ дар парвандаи таҳқиқ мемонанд. Феҳристҳои далелҳо ва журнали ҷустуҷӯ сабти асосии хулосаҳо боқӣ мемонанд.

Барномаро корбар интихоб мекунад. Насби барнома, танзими пайвасти MCP ва ҳамоҳангсозии худкор бо дарахти беруна аз доираи малака берунанд. Муфассал: [references/gedcom.md](references/gedcom.md).

## Истифодаи масъулона

- **Таърихи оила, на пайгирӣ.** Малака аз ҷустуҷӯи суроғаҳо, телефонҳо ё ҳисобҳои кунунии одамони зинда худдорӣ мекунад ва маълумоти онҳоро дар гузоришҳо кам мекунад.
- **Санҷиши дастрасӣ.** Агент метавонад, агар дастгирӣ ва иҷозат бошад, CAPTCHA-и воқеиро як бор тавассути воситаҳои одии браузери дохилӣ санҷад. Агар амали корбар лозим бошад, дар сурати имкон варақаи мувофиқро мекушояд ва URL ҳамроҳ бо амали заруриро медиҳад; воридшавӣ ба ҳисобро корбар анҷом медиҳад. Хизматҳои берунаи ҳалли CAPTCHA, давр задани муҳофизат, пардохт, маҳдудияти ҷуғрофӣ ё суръати дархост ва пойгоҳҳои ифшошуда истифода намешаванд. Ба [дастури браузер](references/browser-and-captcha.md) нигаред.
- **Ҳуҷҷатҳо ё маълумоти ДНК-и шумо бе розигии ошкоратон ба хизматҳои шахсони сеюм боргузорӣ намешаванд.**
- **Бозёфтҳои ҳассос** (бадарға, саркӯб, фарзандхонӣ, натиҷаҳои ғайричашмдошти ДНК) бетарафона ва танҳо ба андозаи зарурати савол баён мешаванд.
- **Мукотибаи иҷозатдодашуда.** Бо иҷозати корбар малака метавонад тавассути абзорҳои мавҷуда ба муассисаҳо дархост фиристад; барои ирсоли аллакай иҷозатдода боз намепурсад. Танҳо пайваст кардани қуттии почта барои ирсол, замимаҳо ё хизматҳои пулакӣ иҷозат намедиҳад. Тамоси расмӣ ва тартиби кунуниро санҷед ва маълумоти вуруд ва мукотибаи хусусии парвандаро берун аз репозиторий нигоҳ доред.

## Саҳмгузорӣ

Манбаъҳои нав дар `references/seed-sources.md` пазируфта мешаванд. Агар маълум бошад, соҳиби санҷидашуда, салоҳият, маҷмӯа, пайдоиш, IDҳо, дастрасӣ, маҳдудиятҳо ва санаи санҷишро сабт кунед; холигиҳоро қайд кунед, на тахмин. Маълумоти шахсиро ба мисолҳо дохил накунед.

Абзорҳои ҷустуҷӯи манбаъ аз китобхонаи стандартии Python ва феҳристҳои мавҷудаи парванда истифода мебаранд. Барои санҷиши таҳлили маҳаллӣ, нуқтаҳои нигоҳдории GWAR, нокомии дастрасӣ, фарогирии номуайян ва сабти далелҳо дар маълумоти сохта `python3 -m unittest discover -s tests`-ро иҷро кунед. Ёфтан ва дидани ҳадафноки FamilySearch аз ҷаласаи мавҷудаи қонунии браузер истифода мекунад; абзорҳои Python пораҳои сабтшударо таҳлил мекунанд. Файлҳои хусусии таҳқиқро берун аз ин нусхаи корӣ нигоҳ доред.
